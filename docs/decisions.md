- 2026-11-26 (security fix asked for by the platform): a borrowed session is rechecked on every request, whether its token comes in the cookie or an `Authorization` header. A no from `canMasquerade` or the new optional `recheck` deletes the borrowed session and reports `onStop` with `revoked: true`. The check is an auth strategy that always returns no user, placed first on the auth collection, and it skips the stop endpoint so `onStop` is reported once. It fails closed: if the check can't finish, the borrowed token is ignored for that request. The delete reads the sessions again in a transaction, so a sign-in made meanwhile is kept and `onStop` is reported once. Masq now refuses a collection that isn't an auth collection. Shipped as 0.1.2.
